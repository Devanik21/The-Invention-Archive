# Research Plan and Stage Gates

## Stage 0 — Scope and archive hygiene
- Keep this directory as a programme workspace.
- Treat concepts as hypotheses until individually checked.
- Preserve existing archive entries and releases.
- Keep the eventual final-paper release separate.

## Stage 1 — Literature and novelty audit
For each of the first ten modules: identify primary and authoritative sources; locate measured performance and uncertainty; record the exact supported claim; identify closest competing abiotic and hybrid methods; classify evidence as terrestrial, laboratory, spaceflight, simulation, review or speculative. Missing data remain missing.

For concepts 11–110, the first pass is taxonomy and feasibility triage, not exhaustive novelty research.

## Stage 2 — Comparative architecture model
Build a single resource-network model. Implement only subsystems for which rates, yields or bounded parameters can be sourced. Use intervals where evidence spans a range. Do not fit missing biological parameters to desired outcomes.

## Stage 3 — First benchmark
Start with regenerative life support and compare:
- an abiotic reference architecture;
- a biological subsystem architecture;
- a mixed biohybrid architecture.

Add photochemical conversion, biomining and biomineralized construction only after the system boundary and first benchmark are reproducible.

## Stage 4 — Uncertainty and falsification
Run structured parameter sweeps and global sensitivity analysis. Report where conclusions reverse. The apparent advantage fails if it depends on excluding feedstock, energy, maintenance, heat rejection, safety, separation or purification.

## Stage 5 — AI contribution
Compare AI-assisted constrained optimization against deterministic multiobjective optimization, random/Latin-hypercube search and applicable process-design baselines. Evaluate feasibility violations, Pareto quality, uncertainty calibration, sample cost and transfer to held-out conditions.

## Stage 6 — Experimental translation
Translate the strongest model result into a low-risk contained experiment using characterized non-pathogenic model systems or public data. No environmental release is implied. Claims about space environments require relevant analogue or flight evidence.

## Stage 7 — Final paper and archival release
Only after stages 1–6: produce the LaTeX manuscript and verified bibliography; compile and inspect a real PDF; regenerate figures from code and archived inputs; execute the verification suite; validate metadata and source manifests; publish with the archive's nine root-level core files plus figures/ and results/; update the parent index without changing unrelated entries; independently verify the remote commit and files.

## Acceptance rule
A stage may be marked complete only when its artifact or test exists and has been inspected. Missing data, unavailable toolchains, non-reproduced claims and negative results remain visible.
