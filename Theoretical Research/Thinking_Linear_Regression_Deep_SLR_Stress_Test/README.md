# Thinking Linear Regression ("Deep SLR"): stress-test release

**Authors:** Devanik Debnath and Xylia (equal contribution). Xylia is the authors' AI research scientist
(multi-agent research system). AI assistance: Claude (Anthropic), under the direction of the authors.

This folder contains the model, baselines, experiments, paper source and notebook for a stress test of a
simple inference-time "critic loop" added to ordinary least squares. The release is a preprint: it is not peer
reviewed, and it makes no biological or clinical claims.

**Headline (honest) result.** The loop has a closed form and is exactly OLS inside the training data
(max difference about 1e-15). Outside the data it is a boundary-anchored, budgeted shrinkage. It helps on
saturating, concave and Engel-curve extrapolation, hurts on linear, logistic and diabetes data, does not
detect regime shifts, and gains nothing from more than one step.

## Layout

| Path | Contents |
|---|---|
| `deep_slr/model.py` | `ThinkingLinearRegression`: fit, closed-form predict, explicit loop, trace |
| `deep_slr/baselines.py` | OLS, clipped OLS, Huber, quadratic, kNN, Gaussian process |
| `deep_slr/data.py` | Five toy families with known truth; Engel and diabetes-BMI real data (offline) |
| `deep_slr/experiments.py` | Nested tuning, 30-seed benchmark, paired statistics with Holm correction, budget curves |
| `deep_slr/plots.py` | All figures and LaTeX tables, generated only from `results/` |
| `scripts/run_all.py` | Reproduces everything (about 45 s on one CPU core) |
| `scripts/build_notebook.py` | Builds and executes `deep_slr_research.ipynb` |
| `tests/test_tlr.py` | Verification: in-support identity, closed form = loop, monotone gap, validation |
| `paper/deep_slr_paper.tex` | Paper source (PDF is built by CI) |
| `results/` | Generated by `scripts/run_all.py` (CSV, JSON) |
| `figures/` | Generated by `scripts/run_all.py` (PNG, PDF, SVG) |

## Reproduce

```bash
pip install -r requirements.txt
python tests/test_tlr.py                       # verification
python scripts/run_all.py --seeds 30           # results, figures, tables
python scripts/build_notebook.py --execute     # notebook with outputs
cd paper && pdflatex deep_slr_paper.tex && pdflatex deep_slr_paper.tex
```

Seeds are fixed (0 to 29). The Gaussian process uses `random_state=0`.

## CI

The workflow `.github/workflows/deep-slr-reproduce.yml` (at the repository root) runs the tests, regenerates
all results, figures and tables, executes the notebook, builds the paper PDF, and uploads them as the
`deep-slr-release` artifact on every push that touches this folder.

## Data

No network is used. Real data come from packages bundled with `statsmodels` (`engel`) and `scikit-learn`
(`load_diabetes`). Toy data are generated from the formulas in `deep_slr/data.py`. Early motivating examples
(an ice-cream toy and a housing example) were illustrative only and are not used as evidence.

## Scope and limitations

Univariate inputs only. Two one-dimensional real datasets. Nested tuning uses only within-support data, so it
cannot see shifts beyond the data. The literature review was not systematic, so novelty claims are "to our
knowledge" and must be verified before submission. See Section 7 of the paper.
