# Problem 2: Genotype-phenotype mapping

Status: not started.

Question. Can we derive a causal theory explaining how genetic information produces phenotype? Specific sub-questions: which genotypes give indistinguishable phenotypes (equivalence classes of a non-injective map), and how much phenotype information can be recovered from a genome?

Why it is open. The same mutation can have different effects on different backgrounds; genes interact nonlinearly; environments modify expression; many genotypes give similar phenotypes; and correlation-based models can mistake causal structure.

Planned first step. Literature review of whole-genome phenotype prediction and causal inference (a recent Bioinformatics review formulates the open problems explicitly). No work has begun.
