## Main idea

A target functional specification passes through a generative proposal stage and then a context-dependent realization stage. These are different sources of uncertainty. If, conditional on context, the target, generated design, and realized phenotype form a Markov chain, the data-processing inequality gives:

$$
I(T;Y\mid C) \leq I(T;G\mid C).
$$

Here, `T` is the desired functional class, `G` is the generated design, `Y` is the realized phenotype, and `C` is context. If an assay is another downstream stochastic stage, it cannot recover the target information lost upstream.

Under the simplifying assumption of independent `K`-ary symmetric proposal and realization channels, the composed mismatch probability is:

$$
e_{\mathrm{tot}}=e_g+e_b-\frac{K}{K-1}e_ge_b.
$$

The associated symmetric-channel capacity is:

$$
C_K(e)=\log_2 K-H_2(e)-e\log_2(K-1),
$$

where `H₂` is binary entropy. The formulas are exact for the stated model, not universal laws of biology. Class-specific failure, correlated error, a shifted context distribution, or continuous and multi-objective phenotypes require a richer model.

## Current reproducible illustration

The included code uses hypothetical values `K = 4`, proposal mismatch `e_g = 0.10`, and realization mismatch `e_b = 0.15`. The exact composed mismatch is **0.23**. The corresponding calculated capacities are approximately **1.373 bits/use** for the proposal stage, **1.152 bits/use** for the realization stage, and **0.857 bits/use** for the composed channel. These are analytical examples—not measurements, estimates of a real model, or experimental outcomes.

## Reproduce the calculations

Requirements: Python 3.10 or later, NumPy, Matplotlib, and NetworkX. Tested here with Python 3.13.5; exact local package versions appear in `results/verification_report.json`.

```bash
python -m py_compile verify_model.py deploy.py
python verify_model.py
python deploy.py --self-test
python deploy.py --validate-only
```

To rebuild the manuscript PDF, install a LaTeX toolchain with `latexmk`, pdfLaTeX, and Biber, then run:

```bash
python deploy.py
```

The deployment validator rebuilds the current manuscript from `paper.tex` and `paper.bib` in a temporary build directory, inspects the output, and stops on missing tools or failed checks. `--self-test` uses a temporary fixture and does not publish. `--publish` is an explicit optional Git operation that requires a clean, authorized local clone and a safe fast-forward push; it does not use stored tokens or force-push.

## What has and has not been verified

- The mathematical helper functions pass unit assertions for entropy endpoints, channel capacity, composition, stochasticity, mutual-information bounds, and invalid inputs.
- The code recreates four plots, two graph-structured schematics, and two flow diagrams, with a fixed seed for synthetic Monte Carlo outputs.
- The current code run is described in [`results/verification_report.json`](results/verification_report.json), [`results/verify_model_stdout.txt`](results/verify_model_stdout.txt), and [`results/numerical_summary.json`](results/numerical_summary.json).
- The context-shift relationship and finite-sample binomial study are deliberately assumed examples, not fitted data.
- This release does **not** test biological sequence function, simulator-to-reality transfer, experimental reproducibility, safety, or efficacy.

## Novelty and relationship to prior work

Information-theoretic limits of noisy genetic regulation have prior foundations, and generative circuit design is already an active research direction. A particularly relevant 2026 study demonstrates in-silico generative design of RNA circuit topologies. This paper therefore does not claim that generative design or information capacity is new. Its proposed contribution is a concise, falsifiable decomposition of proposal uncertainty and realization uncertainty into a two-stage evaluation framework. The literature comparison and residual uncertainty are recorded in [`results/literature_audit.md`](results/literature_audit.md).
