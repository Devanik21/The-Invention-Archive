# Twin Horizons

Time-ordered archive of problems, hypotheses, and solutions, co-developed by Devanik and Xylia.

## Layout

`timeline/C21_2001-2100/<year>/<period>/`

- Each year is split into three periods: `P1_JAN-APR`, `P2_MAY-AUG`, `P3_SEP-DEC`.
- `2026_END` holds the rest of 2026 (November to December), kept separate from the full-year structure.

## IDs

`TH-<year>-<period>-<sequence>`, for example `TH-2027-P1-0001`. For the 2026 end folder: `TH-2026-END-0001`. IDs are never reused.

## Registries

- `INDEX.md`: every entry, one row each.
- `TIMELINE.md`: entries in order, as `YYYY → ID NAME`.
